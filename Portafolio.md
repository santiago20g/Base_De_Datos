#      <p align="center"><strong>💻 Base de Datos 💻</strong></p>

###  ***Objetivo***
Adquirir una comprensión sólida y práctica de los conceptos, teorías y técnicas de gestión de datos, aprendiendo a diseñar, implementar y administrar sistemas de bases de datos relacionales y no relacionales eficientes. Esto permitirá desarrollar el pensamiento analítico necesario para garantizar la seguridad, integridad y optimización de la información en proyectos prácticos aplicados a la toma de decisiones reales.

---

### 🧩 ***Unidad 1***
📖 **Bases de datos relacionales:** Fundamentos y diseño conceptual mediante el Modelo Entidad-Relación, traducción al modelo relacional, álgebra relacional, manejo del lenguaje SQL y administración de bases de datos.

Link de la Unidad 1:
[Unidad 1](Unidad1.md)

---

### ⚙️ ***Unidad 2***  
🧠 **Bases de datos No Relacionales:** Características generales, gestión de bases de datos geográficas, vectoriales, paradigmas NoSQL (Clave-valor, Documental, Columnar, Grafos) y servicios de bases de datos en Cloud Computing. 

Link de la Unidad 2:
[Unidad 2](Unidad2.md)

---

### 🧱 ***Unidad 3***
💻🧱 **Fundamentos a la Ciencia de Datos:** Limpieza y estructuración de datos para ciencia de datos, uso de herramientas de análisis con Python (Pandas, NumPy), visualización de datos y operaciones con bases de datos para Big Data.

Link de la Unidad 3:
[Unidad 3](Unidad3.md) 

---

### 🧭 ***Conclusiones***
💬 El diseño conceptual a través del modelo entidad-relación y su posterior traducción al modelo relacional ayudaron a comprender de forma clara cómo organizar la estructura lógica de la información antes de su implementación física, garantizando la integridad de los datos.

✨ La exploración de bases de datos NoSQL y el uso de gestores como MongoDB, Redis o Neo4j permitió desarrollar una visión moderna y escalable para el almacenamiento de grandes volúmenes de datos no estructurados o altamente interconectados.

🧠 La introducción a la ciencia de datos y el uso de librerías en Python facilitó la obtención de conocimientos prácticos en la limpieza, análisis y visualización de datos, conectando el almacenamiento de información con la toma de decisiones eficientes.
